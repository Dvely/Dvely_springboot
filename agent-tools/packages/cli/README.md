# @qeploy/cli

> **서비스 상태는 [qeploy.com](https://qeploy.com) 에서 알린다.** 서비스가 멈춰 있으면 모든 호출이 "대상을 찾을 수 없습니다" 대신 사이트가 내건 안내([`status.json`](https://qeploy.com/status.json))를 그대로 보인다.

[Qeploy](https://qeploy.com) 커맨드라인. MCP 를 못 쓰는 에이전트·CI·사람용.

```bash
npx @qeploy/cli login
npx @qeploy/cli projects
npx @qeploy/cli status <deploymentId>
npx @qeploy/cli deploy <projectId> --yes
```

토큰은 옵션으로 받지 않는다(셸 히스토리·`ps` 에 남는다). 환경변수 `QEPLOY_TOKEN` 이나 `login` 이 저장한
파일만 읽는다. 종료 코드: 0 성공 · 1 실패 · 2 사용법 오류 · 3 인증 실패(로그인 안 함 포함).

**0.2.0 부터 API 주소는 `https://api.qeploy.com` 이다.** `qeploy.com` 은 웹만 서빙한다. 예전 기본값 `https://qeploy.com`(0.1.x 의 `qeploy login` 이 저장한 주소, `QEPLOY_API_URL`)은 새 주소로 읽으므로 다시 설정할 필요가 없다.

## 짚기 피드백 — `feedback`

`qeploy share` 로 공유한 화면에서 사람이 짚어 남기고 내가 받은 피드백을, MCP 없이 같은 프롬프트로 받는다.

```bash
qeploy feedback                              # 받은 것(ACCEPTED) 목록
qeploy feedback show 12                      # 에이전트용 프롬프트 출력 + .qeploy/feedback/12.md·12.jpg 저장
qeploy feedback fixed 12 --note "패딩을 16px 로"   # 고쳤다고 표시(WRITE). 짚은 사람에게 알림이 간다
```

| 옵션 | 뜻 |
|---|---|
| `--status ACCEPTED\|FIXED\|CONFIRMED` · `--limit 20` | 목록의 상태·개수 |
| `--out <폴더>` · `--screen` | 저장할 폴더(기본 `.qeploy/feedback`), 화면 전체 이미지도 저장 |
| `--note` · `--yes` | 고친 내용 한 줄(300자, 짚은 사람에게 보인다), 확인 없이 진행 |

- 저장한 `.md` 를 에이전트에게 붙이고, 이미지는 첨부한다. 기본 폴더에 저장하면 `.qeploy/.gitignore`(`*`)를 만들어 화면 이미지가 저장소에 올라가지 않게 한다
- 받기 전·받지 않은 피드백은 토큰으로 볼 수 없다. 받기·무시는 `qeploy share` 터미널이나 웹에서 한다

## 내 기기 프리뷰 공유 — `share web`

내 컴퓨터에서 도는 웹 앱 화면을 링크로 공유한다. 받은 사람은 설치 없이 브라우저에서 같은 화면을 보고,
내가 승인하면 조작까지 한다. WRITE 스코프 토큰이 필요하다.

```bash
qeploy share web http://localhost:5173                       # 데스크톱 크기
qeploy share web http://localhost:5173 --viewport 390x844    # 폰 화면 흉내
```

```
보기 링크:    https://k3x9…q2.share.qeploy.com/       ← 남에게 줄 링크. 보기만 되고 조작은 내가 승인
내 제어 링크: https://k3x9…q2.share.qeploy.com/#c=…   ← 나만 쓰는 링크. 열면 바로 조작
Ctrl+C 로 공유를 끝냅니다.
```

| 옵션 | 뜻 |
|---|---|
| `--viewport 390x844` | 화면 크기. 너비 600 미만이면 모바일로 흉내 낸다 |
| `--project <폴더>` | 짚은 요소의 소스 후보를 찾을 프로젝트 폴더. 기본은 지금 폴더(프로젝트일 때만) |
| `--ttl 60` | 링크 유효 시간(분). 기본 60, 최대 1440 |
| `--headed` | Chrome 창을 띄운다(기본은 창 없이) |
| `--json` | 만든 링크 정보를 JSON 으로 stdout 에 출력 |

- 설치된 Chrome·Chromium·Edge 를 찾아 쓴다. 못 찾으면 `CHROME_PATH` 로 실행 파일을 알려준다.
- Chrome 은 늘 **새 임시 프로필**로 띄우고 끝나면 지운다. 내 쿠키·저장된 비밀번호·확장이 없다.
- 공유 탭은 `<url>` 과 **같은 오리진에서만** 움직인다. 다른 주소(다른 포트의 localhost, 사내망, `file://`)로 가는 이동,
  다운로드, 파일 올리기, 붙여넣기(내 클립보드)는 막는다. 새 창·탭은 닫는다.
- 보기 링크로 들어온 사람이 조작을 요청하면 터미널에 묻는다(`y` 면 10분, 30초 안에 답이 없거나 터미널이 아니면 거절).
- 연결이 끊기면 1·2·4·8·16·30초 간격으로 다시 잇는다. 링크가 회수·만료되면 멈춘다.
- Ctrl+C 로 끝내면 링크를 회수하고 Chrome 과 임시 프로필을 지운다.
- 웹의 설정 → **기기 화면 공유**에서 살아 있는 링크(기기 연결·접속 수·남은 시간)를 보고 끝낼 수 있다. 웹에서 끝내면 이 명령도 멈춘다.

### 짚기 피드백

보는 사람이 뷰어의 **짚기**로 화면의 한 곳을 짚으면, 이 명령이 그 자리를 읽어 서버로 보낸다(조작권이 없어도 되고, 기기에는 아무 입력도 가지 않는다).

- **요소**: 종류(태그·역할)·보이는 텍스트·id·짧은 선택자·테두리, 바깥 요소 몇 단계. 입력란은 입력한 값이 아니라 이름표·안내 문구로 가리킨다
- **컴포넌트**: 개발 서버에서 React(fiber)·Vue(`__file`)·Svelte(`__svelte_meta`) 이름과 파일을 안쪽부터 읽는다. React 19 처럼 스택으로만 아는 줄은 변환된 코드의 줄이라, 파일에서 정의한 줄을 다시 찾는다
- **소스 후보**: 프로젝트 폴더에서 컴포넌트 정의·id·보이는 텍스트로 찾은 `파일:줄`과 근거. 약 1초·5개까지, `node_modules`·`.git`·빌드 결과·숨은 폴더는 보지 않는다. **코드는 보내지 않고 상대 경로와 줄 번호만 보낸다.** 지금 폴더에 `package.json`·`.git` 같은 표시가 없으면 찾지 않는다(`--project` 로 정한다)
- **이미지**: 요소 주변을 잘라 낸 것과 그 순간의 화면 한 장
- **범위 넓히기**: 짚은 요소에서 화면 전체까지 범위 후보(6칸까지)를 함께 보낸다. 요소 → 그 요소를 품은 덩어리(`form`·`section`·`nav`·`li`… 역할·id 가 있는 것, React·Vue 3 컴포넌트가 그린 범위. Svelte 는 컴포넌트 칸이 없다) → 화면 순서이고, 테두리가 거의 같은 칸은 하나로 합친다(예: 버튼과 그 버튼만 그리는 `SaveButton`). 보는 사람은 다시 짚지 않고 뷰어에서 한 칸씩 넓힌다. 페이지 안에서 0.4초 안에 계산하고, 넘으면 거기까지만 보낸다(요소 결과는 그대로)
- **화면 전체**: 요소 없이 지금 화면과 그 주소·제목만 보낸다(뷰어의 "화면 전체")
- **영역(끌기)**: 보는 사람이 사각형을 끌면 그 안의 요소(넓이의 60% 이상이 안에 든 버튼·링크·입력란·글·설명 있는 그림, 읽는 순서로 12개까지. 버튼 안의 글자처럼 다른 요소의 일부는 빼고, 입력란은 값이 아니라 이름표로)와 그 영역을 품은 덩어리(영역의 90% 이상을 품은 가장 작은 것부터 화면까지), 가운데 점의 요소를 함께 보낸다. 열린 shadow root 안까지 보고, 요소 2,000개·0.4초 안에서만 센다(넘으면 거기까지, 가운데 요소는 그대로). 잘라 낸 이미지는 요소가 아니라 끈 사각형 + 여백이다
- **빈 자리**: 끈 영역에 요소가 없거나 탭이 빈 곳에 떨어지면 위·아래·왼쪽·오른쪽마다 가장 가까운 요소를 거리와 함께 보낸다("요금제 제목 아래, 푸터 위")
- 손님이 피드백을 남기면 터미널에 알리고 받을지 묻는다(`y` 받기, 그 밖의 답은 받지 않기). 받아야 코딩 에이전트(MCP)가 읽는다. 60초 안에 답이 없거나 터미널이 아니면 **받기 전으로 두고** 웹에서 받는다

## Android 에뮬레이터 공유 — `share android`

에뮬레이터에 떠 있는 앱 화면을 같은 방식으로 공유한다. 보는 사람이 조작권을 받으면 터치·스크롤·키 입력·한글 입력이 에뮬레이터로 들어간다.

```bash
qeploy share android                         # 지금 앞에 떠 있는 앱
qeploy share android --app com.example.app   # 이 앱을 띄워서 공유
```

| 옵션 | 뜻 |
|---|---|
| `--app <패키지>` | 공유할 앱. 없으면 지금 앞에 떠 있는 앱(홈 화면이면 이 옵션이 필요하다) |
| `--any-app` | 앱으로 묶지 않고 에뮬레이터 전체를 공유한다(경고가 뜬다) |
| `--serial emulator-5554` | 에뮬레이터가 여러 대일 때 고른다 |
| `--max-size 1280` | 화면 긴 변(px). 기본 1280 |
| `--bit-rate 2M` | 영상 비트레이트. 기본 2Mbps |
| `--project <폴더>` · `--ttl 60` · `--json` | `share web` 과 같다 |

- **준비물**
  - Android SDK platform-tools(`adb`). `ANDROID_HOME` 이나 기본 SDK 위치에서 찾는다
  - scrcpy 4.x·5.x(`brew install scrcpy`). 그 안의 서버만 쓰고 scrcpy 창은 띄우지 않는다. 다른 위치라면 `QEPLOY_SCRCPY_SERVER`·`QEPLOY_SCRCPY_VERSION`
- 보는 사람 브라우저가 WebCodecs 로 H.264 를 푼다(최신 Chrome·Edge·Safari·Firefox).
- **에뮬레이터만** 받는다. 실제 폰에는 계정·사진이 있어서다.
- **공유는 앱 하나로 묶인다.** 1초마다 맨 앞 앱을 보고, 다른 앱(홈 화면, 에뮬레이터 Chrome 으로 내 localhost 인 `10.0.2.2` 등)으로 나가면 공유한 앱을 다시 앞으로 올린다. 권한 대화상자는 허용한다.
- 한글처럼 키보드로 바로 못 넣는 글자는 에뮬레이터 클립보드에 넣고 붙여넣는다. CLI 는 에뮬레이터 클립보드를 가져오지 않는다.
- **에뮬레이터를 창으로 띄우면 에뮬레이터 클립보드가 내 Mac 클립보드로 넘어온다**(에뮬레이터의 Enable clipboard sharing, 기본 켜짐). 조작권을 받은 사람이 복사하거나 한글을 입력하면 내 Mac 클립보드가 바뀌므로, 시작할 때 경고한다. 끄려면 에뮬레이터 Extended controls(⋯) > Settings > General > Enable clipboard sharing 을 끄거나 `-no-window` 로 띄운다.
- Ctrl+C 로 끝내면 링크를 회수하고 에뮬레이터의 scrcpy 서버와 `adb forward` 를 정리한다.
- **짚기**(`share web` 의 "짚기 피드백"과 같다): `uiautomator dump` 로 그 점의 뷰를 읽고(누를 수 있거나 텍스트가 있는 가장 작은 것, 글자만 있는 Compose 노드는 누를 수 있는 바깥으로), 지금 Activity 와 함께 보낸다. 소스 후보는 Activity·`@+id/…`·`R.id.…`·보이는 텍스트(`strings.xml` 이면 그 이름을 쓰는 레이아웃·코드까지)로 찾는다. 이미지는 `screencap` 날 픽셀을 CLI 가 JPEG 으로 만든다. 비밀번호 입력란의 글은 읽지 않는다. 짚기 하나에 약 2초(실측, API 35 에뮬레이터)
  - **화면 전체**는 덤프 없이 지금 Activity 와 `screencap` 화면만 보낸다
  - **범위 넓히기**: 같은 덤프에서 뷰 → 앱 `resource-id`·설명이 있거나 누를 수 있는 레이아웃, 목록(`RecyclerView`·`ListView`), 앱 자신의 클래스 → 화면 순서로 칸을 만든다. 플랫폼 틀(`android:id/content`)은 칸이 아니다. 넓은 칸의 id(`@+id/…`)도 소스에서 찾아, 그 칸을 고르면 그 줄이 소스 후보 맨 앞에 온다
  - **영역(끌기)**·**빈 자리**: 같은 덤프 한 번으로 끈 사각형 안의 뷰(누를 수 있거나 글·설명·앱 id 가 있는 것, 12개까지. 누를 수 있는 뷰 안의 글자는 그 뷰의 이름이 된다)와 그 영역을 품은 레이아웃, 비었으면 둘레의 뷰를 보낸다. 비밀번호 입력란의 글은 읽지 않는다
  - 접근성 트리는 뷰의 접근성 클래스를 보고한다. `FancyButton extends Button` 은 `Button` 으로 나와, 직접 만든 뷰 이름은 대개 나오지 않는다

## iOS 시뮬레이터 공유 — `share ios` (macOS)

시뮬레이터에 떠 있는 앱 화면을 같은 방식으로 공유한다. 보는 사람이 조작권을 받으면 탭·길게 누르기·끌기·스크롤·영문 입력이 시뮬레이터로 들어간다.

```bash
qeploy share ios                                   # 지금 앞에 떠 있는 앱
qeploy share ios --app com.example.app             # 이 앱을 띄워서 공유
qeploy share ios --udid <UDID> --app com.apple.mobilesafari
```

| 옵션 | 뜻 |
|---|---|
| `--app <번들 ID>` | 공유할 앱. 없으면 지금 앞에 떠 있는 앱(홈 화면이면 이 옵션이 필요하다) |
| `--any-app` | 앱으로 묶지 않고 시뮬레이터 전체를 공유한다(경고가 뜬다) |
| `--udid <UDID>` | 시뮬레이터가 여러 대 켜져 있을 때 고른다(`xcrun simctl list devices booted`) |
| `--scale 0.5` | 화면 배율 0.1~1. 기본 0.5 |
| `--fps 15` | 초당 장 수 상한 1~30. 기본 15 |
| `--project <폴더>` · `--ttl 60` · `--json` | `share web` 과 같다 |

- **준비물**
  - Xcode 와 iOS 시뮬레이터(`xcrun simctl`)
  - [AXe](https://github.com/cameroncooke/AXe) 2.x(`brew install cameroncooke/axe/axe`). 시뮬레이터 화면을 받고 입력을 넣는 데 쓴다. `PATH`·`~/.local/bin`·Homebrew 위치에서 찾고, 다른 위치라면 `QEPLOY_AXE` 에 실행 파일 경로를 준다
- **시뮬레이터만** 받는다. AXe 는 실제 iPhone 도 다루지만, `simctl` 이 켜진 시뮬레이터로 보여 주는 UDID 만 쓴다.
- **클립보드 경고**: Simulator 는 기본으로 Mac 클립보드와 자동 동기화한다. 켜져 있으면 조작권을 받은 사람이 앱의 붙여넣기로 지금 Mac 에 복사해 둔 내용을 볼 수 있어서, 시작할 때 크게 경고한다. 끄려면 Simulator 메뉴 Edit > Automatically Sync Pasteboard 의 체크를 해제한다(CLI 는 설정을 바꾸지 않는다). Cmd+V 는 보내지 않는다.
- **글자 입력**: 보는 사람이 친 글자를 시뮬레이터의 하드웨어 키보드 키로 친다. 클립보드는 쓰지 않는다.
- **짚기**(`share web` 의 "짚기 피드백"과 같다): AXe `describe-ui` 로 그 점의 요소를 읽고(누르거나 입력하는 것, 이름이 있는 가장 작은 것. 스위치 줄의 글자·손잡이는 그 스위치로), 앱 이름·번들 ID·내비게이션 제목과 함께 보낸다. 접근성 트리에는 뷰 타입 이름이 없어서(SwiftUI `SaveButton` 도 `Button`) 컴포넌트 이름은 보내지 않고, 소스 후보는 `accessibilityIdentifier`(SwiftUI `.accessibilityIdentifier("…")`·UIKit `= "…"`·스토리보드 `identifier="…"`·React Native `testID`)와 보이는 텍스트로 찾는다. 이미지는 `axe screenshot` PNG 를 CLI 가 잘라 JPEG 으로 만든다. 입력란에 친 값(비밀번호 포함)은 보내지 않는다. 짚기 하나에 약 0.4~0.7초(실측, iPhone 17 Pro 시뮬레이터)
  - **화면 전체**는 `describe-ui` 한 번으로 앱 이름·번들 ID·제목을 읽고, 보는 사람이 본 화면(스트림 마지막 장, 없으면 `axe screenshot`)을 보낸다
  - **범위 넓히기**: 같은 트리에서 요소 → `accessibilityIdentifier`·레이블이 있는 묶음, 셀·목록 → 화면 순서로 칸을 만든다. SwiftUI 는 바깥 묶음에 이름이 없어 칸이 적다. 카드·폼 같은 묶음에 `.accessibilityElement(children: .contain)` 과 `.accessibilityIdentifier("profileForm")` 을 붙이면 칸이 생기고, 그 칸을 고르면 그 id 를 쓴 줄이 소스 후보 맨 앞에 온다
  - **영역(끌기)**·**빈 자리**: 같은 트리 한 번으로 끈 사각형 안의 요소(레이블·id 가 있거나 누르는 것, 12개까지. 스위치 줄의 글자·손잡이처럼 컨트롤의 일부는 그 컨트롤로)와 그 영역을 품은 묶음, 비었으면 둘레의 요소를 보낸다. 레이블만 보내고 입력란의 값(비밀번호 포함)은 보내지 않는다
  - 영문·숫자·기호, Enter·Tab·화살표 같은 키가 들어간다.
  - **한글은 시뮬레이터 언어가 한국어일 때만 들어간다**(시뮬레이터는 만들 때 Mac 의 언어를 따른다). 한글은 두벌식 자판의 키로 바꿔 치고, 시뮬레이터가 글자로 조합한다. 언어가 한국어가 아니면 한글은 넣지 않고 한 번 알린다.
  - 한글 시뮬레이터의 키보드는 한글·영문 두 상태가 있어서, 영문 글자는 영문 상태에서, 한글은 한글 상태에서 쳐야 한다. CLI 가 필요한 상태를 화면의 키보드에서 읽어 확인하고, 다르면 Caps Lock 으로 바꾼 뒤 다시 읽어 확인한다. 이모지 키보드에 있으면 Ctrl+Space 로 먼저 빠져나온다. 숫자·공백·기호는 어느 상태에서나 같아서 바꾸지 않는다.
  - Caps Lock 으로 언어를 바꾸는 iOS 설정(하드웨어 키보드)이 켜져 있어야 한다. 새로 만든 한국어 시뮬레이터에서는 켜져 있었다. 바꾸지 못하면 그 입력은 넣지 않고 한 번 알린다.
  - 한글과 영문을 오가면 바꿀 때마다 1~2초가 더 걸린다. 그 밖의 글자(é, 漢字, 이모지 등)는 넣지 않는다.
- **공유는 앱 하나로 묶인다.** 2초마다 앞에 떠 있는 앱을 프로세스로 확인하고, 다른 앱(홈 화면, 시뮬레이터 Safari 로 내 localhost 등)으로 나가면 공유한 앱을 다시 앞으로 올린다. 화면 위·아래 가장자리에서 시작하는 스와이프(홈 화면·알림 센터로 가는 길)는 보내지 않는다.
- 터치는 손을 뗄 때 한 번에 재생한다(탭·길게 누르기·끌기). 입력 하나에 0.3초 안팎이 걸려서, 조작이 화면에 보이기까지 조금 늦다.
- 화면이 멈춰 있으면 같은 장을 다시 보내지 않는다.
- Ctrl+C 로 끝내면 링크를 회수하고 AXe 화면 전송을 끝낸다.
